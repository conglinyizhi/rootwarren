# 客户端设计

客户端可以是 Web、TUI、桌面应用或 Agent 工具，但都应遵守同一套 API 和权限规则。

## 阅读优先

客户端首先应提供文档导航、搜索和 Markdown 阅读。编辑器不是首页的主体验，只有拥有读写权限时才显示保存和删除动作。

## 推荐流程

1. 使用启动 URL 建立浏览器会话，或由操作者输入 API 密钥。
2. 加载文档列表。
3. 打开页面阅读原始 Markdown 或渲染后的 HTML。
4. 需要修改时先读取最新内容，再通过 `PUT` 写入完整 Markdown。
5. 删除页面前要求确认，并在成功后刷新导航。
