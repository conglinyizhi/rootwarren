# 访问控制

这个 Wiki 有三种不同的访问凭证。

## 公开浏览

后台开启“允许未登录用户阅读文档”后，未登录用户可以访问首页和 `/d/{slug}`。他们只能看到渲染后的 HTML，不能通过网页编辑文档。

## 启动会话

服务启动时会生成一次性客户端 URL。第一次打开后，服务端用 HttpOnly Cookie 建立当前进程内的读写会话，并清理地址栏中的 Key。

## API 密钥

机器客户端使用 `Authorization: Bearer <key>`。`read` 密钥只能读取和搜索，`read,write` 密钥可以创建、覆盖和删除文档。

后台登录 Cookie 与 API 密钥是两套凭证，不要把后台 token 写进文档或交给普通客户端。
