# rootwarren Agent Guide

`rootwarren` is a MoonBit full-stack Markdown Wiki. Markdown files under `content/` are the source of truth. It uses the full-rabbita full-stack pattern (SSR + frontend hydration + moonback backend API).

## Scope

- Keep the server single-process and native-only.
- Do not add Docker, a database server, MCP server code, OAuth, or microservices.
- Use `content/` for documents and `meta/` for runtime JSON metadata.
- `meta/` is ignored by git. It contains API-key hashes and must not be committed.
- The public browser view is a shared full-rabbita component rendered via SSR and hydrated on the client.

## Layout

- `content/`: Markdown source documents. A document slug is its relative path without `.md`.
- `meta/config.json`: runtime site configuration.
- `meta/api_keys.json`: API-key records. Plaintext keys are never stored.
- `app/`: shared full-rabbita component package (`js+native+wasm`, pure UI, data via `@http` API).
- `cmd/browser/`: frontend hydration entry (`@rabbita.new(@app.app).hydrate()`).
- `cmd/server/`: moonback backend + `@rserver.Server(component=@app.app)` SSR. `main.mbt` and `auth.mbt`.
- `local_storage.mbt`, `storage.mbt`: content-storage abstraction and local filesystem implementation.
- `meta_store.mbt`: JSON-backed config, API-key, and user storage.
- `auth.mbt`: API-key generation, SHA-256 hashing, and JWT/session tools.
- `rootwarren.mbt`: shared rendering helpers (document front-matter, CMark HTML, link rewrite).
- `public/`: static resources. `index.js` is generated by warren (do not commit); `styles.css`/`site.css` are committed.
- `docs/API.md`: client-facing REST API contract.

## Run And Verify

The current MoonBit nightly needs `MOON_CC=clang` on this host because its automatic native archiver discovery selects an invalid path. The project `Makefile` exports it.

```sh
make check
cp .env.example .env
# 编辑 .env 中的 ADMIN_TOKEN 后：
make dev
# 或直接用 warren：
warren dev --browser-entry cmd/browser --server-entry cmd/server --server-target native
```

`make dev` builds the native server and starts the warren full-stack dev server (SSR + frontend hydration + moonback API + live reload) on port `4300`. It also generates `public/index.js` automatically. 后台首次进入使用 `ADMIN_TOKEN` 网页登录（默认用户名 `operator`），登陆后可进入后台管理。`.env` 用 `make init-env` 生成模板。

- `MOON_CC=clang` is required for all native targets (warren + server).
- `.env` is ignored by git; use `.env.example` as the template. Shell environment variables override `.env` values.
- `ADMIN_TOKEN` provides the initial admin password (default username `operator`). Set a persistent Admin Key in the backend after login; only its hash is stored in `meta/config.json`.
- Use `make test` when tests exist. Run `moon fmt` after source changes.
- For the dev-server check: `curl --noproxy '*' http://127.0.0.1:4300/`.
- For the API check: `curl --noproxy '*' http://127.0.0.1:4300/api/v1/docs`.
- For protected API examples, see `docs/API.md`.
- When public browsing is enabled, `GET /llms.txt` exposes a generated Markdown index.
- Do not commit `public/index.js` (warren-generated).

## API Security Model

- Clients authenticate with `Authorization: Bearer <api_key>`.
- Keys have `read` or `read,write` scopes.
- API-key plaintext is shown only on admin creation; only the SHA-256 hash is persisted.
- Use the admin page to create/revoke API keys. It authenticates through the one-time admin URL, or through `ADMIN_TOKEN` form login when configured; both produce the in-process JWT session cookie.
- Do not log request authorization headers or generated plaintext keys.

## MoonBit Notes

- Code blocks are separated with `///|`.
- Package configuration is in `moon.pkg`; imports may declare an alias with `@alias`, and code references it with that `@alias` name.
- Discover current APIs with `moon ide doc`; the toolchain is nightly and exact APIs can move.
- MoonBit `String::to_bytes()` is not the encoding to use for interoperable API-key hashes. `auth.mbt` deliberately uses `@utf8.encode` before SHA-256.
